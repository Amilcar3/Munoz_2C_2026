82 /* Note to Windows users: the initial "C:" on these paths corresponds to
83 * the value of `LV_FS_WIN32_LETTER` in `lv_conf.h`, and should not be
84 * confused with the Windows/DOS drive letter. It is an identifier that
85 * is used to enable LVGL to look up the appropriate driver from a list of
86 * registered file-system drivers. `lv_fs_win32_init()` happens to use the
87 * identifier letter 'C' so "C:" is the driver-identifier-prefix used here.

89 * part of the actual path that gets passed to the OS-level functions.
