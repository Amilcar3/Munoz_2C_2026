2"""Validate LVGL's SPDX 3.0 SBOM against the official SPDX JSON Schema.
3
4This is the validation method recommended by SPDX itself: check the document
5against the published JSON Schema for its spec version. It uses check-jsonschema
6(https://github.com/python-jsonschema/check-jsonschema) as the engine:
7
8 python3 -m pip install check-jsonschema
9
10Usage:
11 python3 scripts/validate_sbom.py [SBOM ...]
12 [--schema URL_OR_PATH] [--spec-version 3.0.1]
13
14With no SBOM argument sbom/lvgl.spdx.json is validated. The schema
15defaults to the official SPDX schema for --spec-version; pass a local path with
16--schema to validate offline.
17"""
