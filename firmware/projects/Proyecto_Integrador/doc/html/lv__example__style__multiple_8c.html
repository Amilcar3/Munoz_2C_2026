void lv_example_style_multiple ( void )

Stack a second style that overrides only a few properties of a shared base.

@title Cascading styles

style_base defines the whole card — fill, border, shadow, radius, padding, text color. style_warning sets only bg_color, border_color, and text_color. The right card has both: the later style wins for the properties it sets, the base shows through for the rest, so one small style re-themes the card without redefining it.
