void lv_example_flex_grow ( void )

Distribute leftover row space by weight.

@title Flex grow

Three buttons share a row: the first has a fixed width and the other two use flex_grow. The free space left in the row is split in proportion to the grow weights, so the grow=2 item receives twice as much extra width as the grow=1 item.

void lv_example_flex_ignore_layout ( void )

Opt one item out of the flex flow.

@title Flex ignore layout

With ignore_layout="true", Flex skips the item entirely: it keeps its manual x/y position and does not occupy a slot. The remaining items lay out as if it were not there, which is useful for overlays, floating badges, or absolutely positioned helpers.

void lv_example_flex_list ( void )

Build a list from a plain flex column.

@title List built from a flex container

A column-flow flex container stacks full-width text headers and buttons. The static flex_list_* helpers wrap the few flex calls needed: LV_FLEX_FLOW_COLUMN for the list, full-width rows for the items, and lv_obj_set_flex_grow so each button's label fills the row next to its icon. The list look is produced with styles applied by hand.

Build a window from a flex column.

@title Window built from a flex container

The static win_* helpers build the window from base widgets: a LV_FLEX_FLOW_COLUMN container with a fixed-height LV_FLEX_FLOW_ROW header bar and a lv_obj_set_flex_grow content area below.
