void lv_example_win_toolbar ( void )

A window whose header carries three symbol buttons over a scrollable label body.

@title Window with title and toolbar buttons

Obsoleto
The lv_win widget is deprecated. See lv_example_flex_win for the recommended way to build a window from a flex container.

lv_win_create fills the active screen and lv_win_add_button places a 40 px LV_SYMBOL_LEFT, a 40 px LV_SYMBOL_RIGHT, and a 60 px LV_SYMBOL_CLOSE button on the header around a lv_win_add_title of A title. Each button fires an LV_EVENT_CLICKED handler that logs its child index. The content area from lv_win_get_content holds a long multi-line lv_label that makes the window scroll.
