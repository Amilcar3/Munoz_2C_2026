Descripción detallada

Backward-compatible aliases for pre-rework example entry points.

The example set was reworked from numbered names (lv_example_arc_1) to descriptive ones (lv_example_arc_set_angles). Code/docs still calling the old names keep building: every retired lv_example_<topic>_<N> is aliased to a valid current example from the same topic. Which specific example a number resolves to is not significant.
