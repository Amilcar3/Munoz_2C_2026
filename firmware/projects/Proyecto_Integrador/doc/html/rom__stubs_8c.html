Descripción detallada

The Espressif toolchains expect these to come from the chip's ROM, so a bare-metal link that does not pull in the ESP-IDF startup code cannot resolve them. The implementations are the simplest that work; they only need to link, never to run, and they are identical across commits so they do not disturb the measurement.
