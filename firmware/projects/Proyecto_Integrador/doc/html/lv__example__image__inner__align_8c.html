void lv_example_image_inner_align ( void )

When the widget is larger than the image, inner_align chooses where it sits.

@title Image inner align

Each image widget here has a fixed 140x100 size while img_example_lvgl_logo is smaller, so the source occupies a fraction of the widget. inner_align picks how the image is positioned inside the widget box — top_left, center, bottom_right for fixed placement; contain, cover, stretch, tile for fit modes. A coloured background makes the unused area visible.
