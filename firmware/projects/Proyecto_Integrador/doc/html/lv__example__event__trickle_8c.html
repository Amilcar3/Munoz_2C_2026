void lv_example_event_trickle ( void )

Forward pressed state from a flex container down to its children.

@title Event trickle to children

A 290x200 container with LV_FLEX_FLOW_ROW_WRAP holds nine small sub-containers, each with a numbered label. The container is flagged with LV_OBJ_FLAG_EVENT_TRICKLE so its input events reach the children; a single white-on-black style is added to the container for LV_STATE_PRESSED and to each sub-container for LV_STATE_FOCUSED, so pressing the container flips the whole group to the dark style.
