Descripción detallada

Interfaz gráfica de smartwatch para display redondo GC9A01 (240×240) con LVGL 9.x.

Provee tres vistas conmutables renderizadas sobre un display TFT circular de 1.28" controlado por el GC9A01:

  • ALL_IN_ONE_VIEW_ALL : reloj analógico + HR + SpO2 + curva PPG reducida.
  • ALL_IN_ONE_VIEW_CLOCK : reloj analógico a pantalla completa.
  • ALL_IN_ONE_VIEW_PARAMS : HR + SpO2 + curva PPG ampliada con anillo animado de latido.
Nota
Todas las funciones de este módulo deben llamarse desde la tarea que ejecuta lv_timer_handler() (DisplayTask en Proyecto_Integrador.c).

Construye los widgets de las vistas ALL, CLOCK y PARAMS dentro del contenedor padre indicado (o la pantalla activa si parent es NULL). Arranca mostrando ALL_IN_ONE_VIEW_ALL; las demás vistas se ocultan.
